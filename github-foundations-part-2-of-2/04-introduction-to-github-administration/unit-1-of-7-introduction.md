# Introduction

> 📘 Note: These notes follow a two-line progressive summary method.
> The apparent repetition is intentional — each line consolidates previous material to reinforce recall.

Admins must protect assets while providing needed access.
> Grant the access that is required by each person and group.

To assign correct access, you must first understand the tasks of each group and the options available in your VCS platform (e.g. GitHub)
> Understand the tasks at hand and the options available to you so that you can grant correct permissions.

We will learn about the permissions hierarchy, GitHub admin tasks at each level of the hierarchy and the options for authentication.
> Understand the tasks and options at each level of the permission hierarchy to grant correct access and safeguard assets.

## Learning objectives

We will learn to centrally manage authentication, authorisation and repository access across an organisational structure with a hierarchy of permissions.
> Protect people and assets with permission structures that are appropriate to the organisation.
