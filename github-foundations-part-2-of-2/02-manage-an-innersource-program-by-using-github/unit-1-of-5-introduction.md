# Introduction

> 📘 Note: These notes follow a two-line progressive summary method.  
> The apparent repetition is intentional — each line consolidates previous material to reinforce recall.

Proprietary software benefits from keeping its intellectual property (IP) private, while open-source software benefits from permitting contributions
> Projects can be proprietary, open-source, or even Free and Open-Source (FOSS) AKA Libre

InnerSource software aims to provide a hybrid approach between proprietary and open-source software
> Projects can be proprietary, innersource, open-source, or libre

We will learn how to manage an InnerSource project on GitHub
> GitHub supports Libre, Open-Source, InnerSource and Proprietary software

# Learning objectives

- Contrast user-owned from organisation-owned
- Recommend the number of GitHub organisations needed
- Create discoverable repositories
- Robust README
- Issue and PR templates
- Transparent repos
- Measure the success of InnerSource
- Distribute an InnerSource toolkit

> GitHub supports Libre, Open-Source, InnerSource and Proprietary software with a range of tools and templates
