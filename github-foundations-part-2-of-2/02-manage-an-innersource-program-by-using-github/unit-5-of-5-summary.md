# Summary

We learned how to build an InnerSource project on GitHub with proper discoverability, guidance and maintenance
> Make InnerSource projects discoverable within your organisation, provide guidance in README, CONTRIBUTING and templates, and provide thoughtful maintenance

**Outcomes**
- Contrast user-owned and organisation-owned projects
- Make recommendations about the number of GitHub organisations you should have
- Create discoverable repos
- Robust READMEs
- Issue and PR templates
- Transparent repos
- Measure success of InnerSource
- Distribute your InnerSource toolkit

> InnerSource helps organisations reuse code, standardise practices and reduce friction
